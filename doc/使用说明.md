公开入口：[CES 展台方案编辑器](https://mao-ces-booth-editor.oldmao.chatgpt.site/)，刷新后检查版本 v0.1.13。各自浏览器保存，跨电脑用 JSON 导出／导入。

本地验收服务「验收-悬浮物料栏与人物」：`python3 -m http.server 8876 --bind 127.0.0.1`，访问 http://127.0.0.1:8876/ 。也可离线打开根目录 `index.html`。

## 编辑与浏览
- 点击画布顶部「物料」悬浮按钮，展开后拖入地面／水平台面添加；也可点击物料卡添加。左栏只保留图层管理、选中物料属性和场地设置。
- 物料包括电视、前台、机器人、闺蜜机、圆桌、L 型台、吊楣、笔记本、摄像头、A4／A5 竖牌、易拉宝、听讲椅、工作人员及游客。点击画布物体或左侧图层选中。
- 选中物体→「放置」→点击水平表面，底部贴合落点；Esc／取消退出。放置后移动桌子不会带动物品。
- 图层区底边把手可拖动高度，眼睛图标控制显隐；高度记在本机。
- 人物身高默认1.75米，游客白模、工作人员蓝马甲；可调等比缩放、马甲颜色和已有动画。Walk／Run 原地播放。
- 彩色轴双向移动；位置和尺寸以米为单位。低频微移在折叠区，每步 0.1 米。
- 电视用 48/55/65 寸按钮或输入自定义英寸。闺蜜机可切换横竖屏，整体尺寸由屏幕和底座决定。圆桌改宽/深时保持圆形。
- L 型台四个尺寸：横边长度、横边宽度、纵边长度、纵边宽度；边宽不超过与它相交的另一边总长度。可单独调台高。
- 所有物体支持 ±45°；手输朝向按 45° 取整。打开「靠墙吸附」立即贴最近墙，拖动/改尺寸后保持贴墙；旋转自动解除吸附。重新开关吸附可改贴另一墙。
- A 是左墙，B 是后墙，各有显示开关。点击「A / B 墙长互换」，两墙由 5.5/6.1 米变为 6.1/5.5 米，各墙物料不搬家；自由物料按相对位置适配，靠墙物料保持贴墙。
- 编辑时鼠标拖空白旋转、右键平移、滚轮缩放。物体底部绿色环可拖动旋转，每档45°。指南针中北为场地前方（+Z）。
- 按 WASD 开始步行，视点高度固定1.75米，W前进／S后退／A左移／D右移；允许鼠标锁定后直接移动鼠标转头。空格切换浏览，Esc退出并还原编辑视角；输入框中不触发行走。
- 允许物料越界或重叠；越界时侧栏提示。步行没有碰撞阻挡，可穿过物料和墙体。这是排布草图，不是施工图。

## 游客路线
用来演示「一个游客进展台后先看什么、后看什么、走哪条路」。路线跟着每个展台方案一起保存和导出。

1. **进入**：点顶栏「路线」，画面切成平面图纸（北在上、东在右），能看到过道、展台、墙和所有物料的占地。这时顶栏只剩「退出路线」，方案标签和左侧栏都收起；要切换方案先退出。左边「路线方案」面板可左右拖宽（最窄 240、最宽窗口的 70%），宽度记在本机。
2. **标兴趣点**：在图纸上点一个物料→右栏「设为兴趣点」。物料上出现编号圆标①②③，旁边有个站位点（游客站哪儿看）。站位点可拖；可改名、改默认停留秒数（默认 5 秒）。删物料不会让编号重排。
3. **建大方案**：左栏标题右边的「+」新建，选游客从哪边来（北过道东→西、北过道西→东、西过道南→北、西过道北→南、其他）。入口、出口两个点会自动放在过道上，可拖。
4. **建子方案、排顺序**：点大方案那一行右边的「+」新建子方案（选中的行是浅色底），然后在图纸上依次点兴趣点，就排成「入口→③→①→出口」。右栏可拖动换顺序、删某一站、改这一站停留秒数。
5. **自动绕路**：每次改动程序自己算路，图上只画选中那个子方案的绿色路线和箭头，会绕开桌子、电视、人物和显示中的墙。某一段走不通就画红色虚线，并提示「③→⑤ 走不通，被『前台』挡住」；有走不通的子方案不能播放。吊楣和桌上的小物件不挡路，隐藏的物料也不挡。
6. **播放预览（在编辑画布里直接看）**：选好子方案，画布最下方有一条播放条：从头、播放/暂停、进度条（里面的小圆点是各站的位置，开不开「跳过停留」都在，点一下跳过去）、时间、倍速（点一下切一档：1×→2×→0.5×），右边是三个纯图标的视角键（平面、透视、游客），选中的那个才显示名称——「平面」是回到图纸（游客是一个小人带一块视野扇形，可以边看边改），「透视」是在场外看游客走，「游客」是游客眼睛的视角（眼高默认 1.75 米，点画面后移动鼠标转头，旁边的「视线归位」回到前进方向）。三种视角用同一条时间线，切换时进度不丢；左右两栏始终可编辑，在 3D 里点「+」加路径点会自动回到平面。空格暂停/继续，窗口切走会自动暂停。预览里每站固定只停 3 秒（只是示意，所以右栏每个路径点不再设停留时间）；播放键右边的「下一个停留点」可一键跳到下一站，播放中跳了继续播、暂停中跳了仍暂停；拖进度条前在播放，拖完继续播，拖前暂停，拖完仍暂停。平面图里的接待员、游客等人物画成顶视小人（肩膀胶囊、头部圆、两只脚尖），朝向和物料朝向一致，样式同普通物料。播放条最右边的齿轮是「设置」，目前只有一项「跳过停留」：打开后播放时不在兴趣点停下、直接走完全程（只存在本机，不进方案）。

**让 Agent 批量写路线**：见 [路线草稿-Agent格式](路线草稿-Agent格式.md)。Agent 生成的是新方案文件，用顶栏「导入」打开，会多出一个方案标签，原方案不动。

**已知代价**：路线存在方案文件里。**用旧版下载的编辑器打开含路线的新文件，方案和物料都在，但路线会丢**（旧版不认识它，也不报错）。要保留路线，请用新版编辑器打开，或重新「下载编辑器」。反过来，旧版导出的文件在新版里正常打开，只是没有路线。

**默认打开什么**：浏览器里没存过方案时，打开的是 `doc/Files/CES-02.json` 里的方案「02」；存过就打开上次的。下载的离线编辑器里也内置了「02」。

## 方案文件与编辑器分离
- 「另存方案 +」复制当前布局为新标签；点击标签快速比较，每个方案独立自动保存到当前浏览器。
- 顶栏选「当前方案」或「全部方案」→「导出 JSON」：只导出方案数据，文件可跨电脑带走。
- 「下载编辑器」：下载不带用户布局的离线工具 HTML。打开它 →「导入方案」→ 选择 JSON，即可继续编辑。
- 「导入方案」也接受旧版下载的 HTML，只提取布局数据，不执行导入文件。导入追加方案，不覆盖已有标签。
- 同一个编辑器同时开多个窗口时，另一窗口修改后，本窗口停止自动覆盖并提示导出备份。浏览器清理数据会丢本机工作副本，因此重要方案请导出 JSON。
- 升级或清理浏览器前先导出 JSON 备份；若很早的旧版本只提供 HTML 下载，则先下载旧 HTML，再在新版导入。
