# 游客路线模拟：技术实施计划（兴趣点 + 自动绕路版）

## 0. 一句话
在物料上标兴趣点（①②③…）→ 子方案就是一串编号「入口 → ③ → ① → ⑤ → 出口」→ 程序自动算出不穿模的走法 → 回 3D 播放、暂停、拖进度、第一人称鼠标转头。

用户确认的要求（2026-11-13）：
- 路线在一个**独立的平面图纸编辑模式**里创建、编辑、查看，像在图纸上操作。
- 在元素上标兴趣点；路线按兴趣点顺序规划，自动绕开障碍物、不穿模；方案显示成「从几号到几号到几号」。
- 大方案（4 个来向）→ 子方案（几种参观顺序）；可切换播放。
- 具体走法以后再定；现阶段只跑通机制。测试数据：1 个大方案 + 3 个子方案。
- 派给 Claude（Codex 没额度）。

不做：手画路线、手动拐点、外部 Agent 文件往返、AI 自动生成路线、多人、工作人员陪同、对话脚本、手机适配。

## 1. 基线事实（接手时复核，以代码为准）
- 无框架单页离线应用：`python3 src/build.py` 把 `src/` 打包成 `index.html`，只改 src。不引入新依赖、框架或服务端。
- Git：main 分支。开工前 `git status` 必须干净；别的任务若留着 `src/` 的未提交改动，**停下问用户**，不要替别人提交或覆盖。新功能在 `feat/visitor-routes` 分支做。
- 方位：北 +Z，南 -Z，东 -X，西 +X。A 墙在 -X（东），B 墙在 -Z（南），可能被隐藏（`room.wallA/wallB`）。过道几何在 `src/venue.js`：`venueGroup.userData = {bounds, aisleX, aisleZ}`，北过道宽 aisleZ（12ft≈3.66m），西过道宽 aisleX（20ft≈6.1m）。
- 物料：`objects` 是 THREE.Group，`userData = {type, id(数字，稳定), size:[w,h,d], ...}`，`position` 在地面（y=底部），`rotation.y` 是朝向。尺寸按 `size` 不是网格缩放。
- 屏幕正面朝物料**本地 +Z**（`app.js` 里 screen-purpose 面放在 +Z）。电视屏中心高度 = position.y + size[1]/2；闺蜜机屏中心约 1.22m。
- 存储：`layout()` 只返回 `{room, objects}`；`validateLayout`、`restore`、`parseWorkspace` 都要接新字段，否则会被丢掉。workspace `version:2`，key `ces-workspace-v2:<workspaceId>`。撤销 = 整份 layout 快照，`checkpoint()` 记一步，最多 40 步。
- 自由步行：`setWalking()`、鼠标锁定、眼高 1.75、FOV 65；`animate()` 里每帧 `people.update(dt)`。人物模型有 Idle / Walk 动画。
- 写界面前读 `/Users/mao/Documents/Coding/Development/MyLibrary/core/rules/design-global.md`（lucide 图标、hover、不加卡片阴影、文字从简等）。沿用 editor.html 现有配色（主色 #176b55）和控件样式。

## 2. 用户怎么用
1. 顶栏「路线」→ 进入**路线编辑模式**：全屏平面图纸盖住 3D，北在上东在右；画出过道、隔壁展位、展台、墙、全部物料占地轮廓和名字、指南针、比例尺。（参照 demo 的图纸样子）
2. **标兴趣点**：在图纸上点一个物料 → 右栏「设为兴趣点」。物料上出现编号圆标 ①，旁边自动放一个**站位点**（小人脚印圆点，虚线连到物料）。可拖站位点微调；可改名（默认物料名）和默认停留秒数（默认 5）；可「取消兴趣点」。
3. **大方案**：左栏新建，选来向（北过道·东→西 / 北过道·西→东 / 西过道·南→北 / 西过道·北→南 / 其他）。来向决定默认**入口、出口**两个点，画在过道上，可拖动微调。
4. **子方案**：在大方案下新建 → 进入「排顺序」状态：在图纸上依次点兴趣点，加入顺序；Enter/「完成」结束。右栏显示站列表「入口 → ③ → ① → ⑤ → 出口」：拖动排序、删除某站、改该站停留秒数（默认取兴趣点的默认值）。同一兴趣点可出现多次。不选任何兴趣点 = 只路过。左栏子方案行显示编号串和时长。
5. **自动路线**：每次改动后自动重算，图上画出绿色路线、箭头、站点编号。某段走不通：该段画红色虚线直连，右栏提示「③ → ⑤ 走不通，被『前台』挡住」（挡住物取寻路失败时离直线最近的障碍物即可）；有走不通的段时不能预览。
6. **3D 预览**：同 demo——底部播放条（路线下拉、从头、播放/暂停、带停留刻度的进度条、时间、0.5×/1×/2×、总览/第一人称、视线归位）、顶栏「回到路线图」「退出」。到站停留时自动看向该物料，走路时看前方，鼠标转头叠加在上面。

## 3. 数据（放在每个展台方案的 layout 里）
```
layout.tour = {
  pois:   [{ id, objectId, num, name, dwell: 5, stand: [lx, lz] }],      // stand 是物料本地坐标
  groups: [{ id, name, approach, entry: [x, z], exit: [x, z],
             routes: [{ id, name, speed: 1.0, eyeHeight: 1.75,
                        stops: [{ poiId, dwell? }] }] }]
}
```
- 单位米，世界坐标 XZ。`stand` 存物料本地坐标（随物料平移旋转），世界坐标 = 物料变换后的点。
- `num` 是给人看的编号：新建取当前最大值 +1，**删除不重排**（避免「3 号是谁」对不上）。
- 自动路线、时长都是**算出来的**，不存。
- 物料被删除或兴趣点被取消：引用它的站在列表里显示「已失效」并跳过（路线照算），不自动删站。撤销能恢复。
- 复制物料不复制兴趣点；复制整个展台方案时 tour 一起深拷贝。
- `validateLayout` 校验 tour（有限数字、id 唯一、引用存在或标失效、approach 枚举、speed>0、dwell≥0、数组长度上限：pois≤100、groups≤20、每组 routes≤30、每条 stops≤50）。tour 不合法时丢弃 tour 并提示，物料照常读。没有 tour 的旧数据照常读。
- **不升 version**（仍是 2，tour 可选）。已知代价：旧版下载的编辑器打开新文件会丢路线 → 写进使用说明。
- 撤销：标/取消兴趣点、拖站位点（松手时）、增删排序站、改数值、改入口出口都走现有 `checkpoint()`。

## 4. 自动绕路（纯函数，可单测）
1. **能走的区域**：展台地面 ∪ 北过道 ∪ 西过道（从 venue.js 的几何算，限制在 venue bounds 内）。区域外都是不可走。
2. **障碍物**：每件物料的占地形状，向外膨胀**人体半径 0.3m**：长方物料 = 按 rotation.y 旋转的矩形；小圆桌 = 圆；L 型台 = 两个矩形（按 lengthA/widthA/lengthB/widthB 复核真实几何）；人物（staff/visitor 摆件）= 半径 0.3 的圆。可见的 A/B 墙也是障碍。**不算障碍**：悬空吊楣（fascia），以及放在别的物料上的小件（laptop、webcam、acrylic*）。被隐藏的物料不算。
3. **网格 A\***：0.1m 一格，8 方向，不许斜着切过障碍物的角。起点到终点逐段算：入口 → 站位1 → 站位2 … → 出口。
4. **拉直**：对 A* 的折线做「能直接连就跳过中间点」的简化，每次检查整段线段（带人体半径）不碰障碍。
5. **站位点不可走**（在障碍物里或区域外）：该站标红，提示「④ 的站位被挡住了，拖一下站位点」，不偷偷挪位置。
6. **默认站位**：物料正面（本地 +Z）外侧、距占地边缘 1.0m；不可走就依次试左、右、背面；都不行就放正面并标红。
7. 预算：20 个兴趣点、10 条路线时，全部重算 < 200ms（实测记录）。超了再优化，不预建后台线程。

## 5. 3D 播放（照 demo）
- 时间轴纯函数：`compileRoute(path, stops)` → 走 / 转身（拐角原地转，90° 约 0.4s）/ 停留 段；`sampleRoute(compiled, t)` → 位置、身体朝向、视线、当前阶段、第几站。拖进度条直接按时间采样，往回拖结果一致。
- 第一人称：相机 = 游客位置 + 眼高，隐藏游客自己。点画面锁定鼠标，移动鼠标转头（俯仰限位）；锁不上就按住拖动；Esc 释放并暂停。停留时默认看物料中心（屏幕类看屏中心），走路时看前方。拖进度 / 切路线 / 「视线归位」清零转头偏移。
- 游客：临时人物（不进方案数据），走路放 Walk、停留放 Idle，动画进度跟时间轴；`people.update(dt)` 跳过它，避免推两次。模型未加载先用胶囊占位。
- 键盘：空格播放/暂停；WASD 无效；输入框和中文输入法不拦截；窗口失焦就暂停。
- 模式：editor / freeWalk / routeEdit / routePlay 四选一，同一时间只有一个模式控制相机和键盘；进出走同一对函数，退出恢复原相机、轨道中心、FOV、选中状态。切方案、导入、删除正在播的路线都先退出播放。

### 必测
- 寻路：直路；绕单个矩形；绕旋转 45° 的矩形；绕圆桌；绕 L 台；两物料间 0.5m 窄缝（人宽 0.6 走不过 → 报走不通）；0.7m 缝（能过）；站位在障碍里；入口在区域外；不切角；拉直后整条路线逐段复检不碰障碍；吊楣和桌上小件不挡路；隐藏的墙不挡路。
- 坐标：北 +Z、西 +X；旋转物料的 stand 本地→世界换算。
- 时间轴：起止、零长度段、停留、拐角转身、往回 seek 一致、倍速、sample 无副作用。
- 数据：旧数据没有 tour 能读；坏 tour 被拒且物料不丢；删物料→站失效→撤销恢复；复制物料不带兴趣点；复制方案深拷贝不串改；编号删除不重排。
- 原有 `src/test*.cjs` 全跑；原来就失败的（如墙长互换那条）单独报，不算本次。
