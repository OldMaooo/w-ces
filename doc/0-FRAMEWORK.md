# CES 展台草图方案

## 用途与边界
用于对比展台物料排布的桌面 3D 草图。保留空间关系，不追求施工精度，不做碰撞检测。以现有单页离线编辑器持续修改，不引入账号或云同步。

- 悬浮物料栏、听讲椅、单模型两种角色、人物动画及图层调整均已实现；详细操作与验证见 [使用说明](使用说明.md)。
- 新物料／人物及表面放置定向检查通过；原全量回归仍有墙长互换旋转断言失败。待用户验收拖入手感、人物大小和动画观感。

## 已确认功能（2026-11-13）
- 左侧工具栏更紧凑，保留拖宽；低频微移默认折叠。
- A 为左墙，初始长 5.5 米；B 为后墙，初始长 6.1 米。墙长互换时，靠墙物料保持 A/B 归属与实际尺寸；地面自由物料整体转90°并调整位置。两墙可分别隐藏。
- 指南针北为场地前方（+Z），随观察方向转动。
- WASD 进入人眼高度 1.75 米的步行浏览，空格进入/退出，鼠标拖动看方向；退出还原编辑视角。
- 电视支持 48/55/65 寸和自定义英寸，按 16:9 换算。闺蜜机初始 27 寸，白色圆底单杆，可切换横屏/竖屏。圆桌为单根金属腿。
- 物体可立即吸附最近的 A/B 墙，调整屏幕尺寸后保持贴墙；手动旋转解除吸附。每次旋转 45 度，手输角度也按 45 度取整。
- L 型台独立添加，横边长度/宽度、纵边长度/宽度分别可调，台高可调。
- 方案标签快速另存和切换，修改自动存本机。每个方案的布局和撤销独立。

## 桌面物料与点击放置（2026-11-13）
- 笔记本电脑、电脑摄像头、A4（210×297mm）和 A5（148×210mm）竖版亚克力牌。新建立牌分别添加，旧方案的原立牌保持原尺寸。
- 易拉宝默认画面 80×200cm，含底座整体约 84×208×35cm；可调整整体尺寸。
- 选择物品→点「放置」→点击另一物品朝上的水平表面；底部贴合点击面，保持朝向，自动退出放置。悬停显示落点，Esc 或「取消」退出。侧面不接受放置，圆桌/L台按实际表面命中，不按外接方框计算。
- 放置绕过 0.1m 网格、解除靠墙吸附、支持一次撤销/重做和现有保存/导出。只记录物品位置，不建立依附关系；移动桌子不会自动带走桌上物品。未做越过桌边或物品互相重叠的碰撞检查。

## 悬浮物料栏与人物（2026-11-13，v0.1.13）
- 物料入口在画布顶部悬浮「物料」按钮中，按展台/设备/展示/人物分组；左栏不再显示添加物料。拖入画布水平表面即可创建并贴合，保留点击卡片快捷添加。拖出画布不新增。
- 左侧独立图层管理，底部把手可上下拖高，使用 Lucide Eye/EyeOff 显隐按钮。图层区高度作为本机界面设置保存，不进入方案 JSON。
- 听讲椅为无扶手、四腿的简易会议椅，默认 46×82×50cm；沿用尺寸、位置、旋转、复制、显隐与放置。
- 人物只引入一个 Quaternius Animated Men Pack 的 Man GLB，以工作人员和游客两种默认配置使用：同样的白模材质，工作人员躯干蓝色 #165DFF、袖子仍白；游客默认全白。马甲颜色可改。
- 使用与现有 Three.js 匹配的 GLTFLoader、SkeletonUtils.clone 和每实例 AnimationMixer；动画来自原资产。支持位置、等比缩放、朝向和动画选择；Walk/Run 原地播放，不自动在场地移动。
- 人物数据只有角色类型、等比缩放、动画名和衣服颜色；沿用版本2方案快照、撤销和导入导出。模型及图标内嵌到下载编辑器，离线不依赖 CDN。没有重新建模、行走路径或复杂人群系统。

## 编辑器与方案分离（用户追加确认）
- 编辑器是离线 HTML 工具；「下载编辑器」不携带用户布局。
- 方案是独立 JSON 数据；「当前方案 / 全部方案」控制导出范围。换编辑器版本只需导入 JSON。
- 方案文件包含版本、活动方案和布局，布局包含房间与物料；侧栏宽度、本机存储标识属于编辑器设置，不写入方案 JSON。
- 旧版下载的 HTML 仍可导入：仅读取其中的 JSON，不执行导入文件中的代码。导入追加为独立方案，不覆盖现有方案。
- 本机自动保存只是工作副本；跨电脑或长期保留用 JSON 文件。多窗口并发修改时阻止旧窗口静默覆盖，提示先导出其独立副本。

## 展台尺寸与实时自动保存（2026-11-13，v0.1.16）
- 用户要求恢复我们展台的两条场景尺寸。仅显示本展台长宽，沿用原位置、使用较淡的文字；其他地面保持无字。
- 原先已有操作结束后的本机自动保存，但数值框未失焦时刷新会丢本次输入。现将合法输入即时应用和保存，输入框仍能删空、输入负号等中间态；不改写当前输入，失焦后才规整。
- 数值、屏幕名称、人物比例/颜色及吊楣跨度支持输入时保存；每次聚焦编辑只记录一次撤销。中文组字完成才更新屏幕名称。
- 物料拖动/旋转变化通过120ms节流保存，操作结束与页面离开再立即保存。新增、删除、复制、显隐和方案切换继续沿用自动保存。
- 「已实时保存到本机」表示当前浏览器的本地工作副本。导出 JSON 用于文件备份和换设备；没有新增云同步或自动覆盖导入文件。原多窗口覆盖保护保留。
- 验证：先红后绿复现未失焦刷新；最终断言刷新后的输入框与物料列表，覆盖新增、未结束拖动变化、删空、负号和单次撤销。定向脚本 src/test-autosave.cjs；尺寸截图 tmp/autosave-dimensions.png。真实中文输入法未代替用户试验。
