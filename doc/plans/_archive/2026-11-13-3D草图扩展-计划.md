# 3D 草图扩展
## 范围与已确认规则
按本轮用户请求扩展现有离线单页编辑器：紧凑侧栏、A/B 墙长互换、1.75m WASD 行走与空格切换、独立墙可见、27 寸闺蜜机横竖屏、靠墙吸附、小圆桌、电视预选/自定义英寸、四参数 L 台、方案标签与 45° 旋转。
A=左墙（初始5.5m），B=后墙（初始6.1m）。互换墙长时保持每面墙的物料归属、数量、方向和相对顺序，通过 X/Z 归一化位置调整间距；物料实际尺寸保持。此处按用户例子实现自适应换边，不把物料搬到另一面墙。
## 基线与安全
无 Git 仓库，不初始化或提交。原版源码及离线 HTML 已备份 tmp/backup-2026-11-13/。浏览器当前未保存布局不可读取，不刷新用户页面。支持导入旧下载 HTML 的 seed 数组。

- src/editor.html：紧凑样式、两行工具区、方案 tab、物料和条件属性、场地控制；保留侧栏拖宽。

- 靠墙开关立即移到最近 A/B 墙，固定贴墙方向并限制沿墙位置；手动旋转解除吸附。
