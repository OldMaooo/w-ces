# 游客路线模拟：技术实施计划（简化版）

## 0. 这一版改了什么
用户 2026-11-13 的要求：
- 整套流程做简单；路线在一个**独立的俯视平面图编辑模式**里画、改、删，像在图纸上画线一样。
- 这一阶段把功能和机制跑通就行，具体路线怎么走以后再定。
- 测试时先建 1 个大方案，下面挂几个子方案，把整个流程跑一遍。

因此去掉：兴趣点实体、外部 Agent 规划文件往返、自动寻路（A*）、场景指纹、请求编号去重、后台线程、存储版本升级。

一句话：**用户在平面图上画折线，并标出停留点和看向哪里；应用照这条线让人走，在 3D 里播放。**

## 2. 用户怎么用（完整流程）
1. 顶部工具栏点「路线」，进入**路线编辑模式**：3D 画面被一张全屏平面图纸盖住，北在上、东在右。图上有：会场过道（浅灰）、展台地面、A/B 墙、所有物料的占地轮廓和名字、指南针、比例尺。
2. 左侧栏是两层列表：**大方案**（比如「北过道 · 东→西」）→ 下面的**子方案**（比如「看屏幕后体验 A」）。都可以新建、重命名、复制、删除。大方案有个「来向」标签：4 个固定来向加「其他」，只用于分类。
3. 选中一个子方案点「画路线」：在图上逐个点击放折线点，双击或按 Enter 完成。第一个点是起点（绿），最后一个点是终点（红），线上带箭头标出走向。
4. 编辑：拖点移动；点线段中间的小圆点插入新点；选中点后按 Delete 删除；滚轮缩放，按住空格（或右键）拖动平移，「适应画面」一键回到全图。
5. 选中一个点，右侧属性栏可以打开「在这里停留」：填停留秒数（默认 5 秒），再点「选看向目标」并点图上任一物料，停留时就看向它（不选就看前进方向）。停留点在图上显示成带编号的大圆点，并画一条看向虚线。
6. 子方案还有两个参数：走速（默认 1.0 m/s）、眼高（默认 1.75m）。
7. 如果某段线穿过了物料或墙，这段标红，并提示「第 3→4 段穿过了 屏幕 2」。只提醒，不拦着；整个功能也不做自动绕路。
8. 点「在 3D 中预览」：回到 3D 场景，出现一个模拟游客和地面路线，底部出现播放条（见第 4 节）。点「回到路线图」继续编辑；点「退出」回到原来的编辑视角。

## 3. 数据（随展台方案保存）
```
layout.routes = {
  groups: [{ id, name, approach: 'north-e2w'|'north-w2e'|'west-s2n'|'west-n2s'|'other', routes: [Route] }]
}
Route = { id, name, speed: 1.0, eyeHeight: 1.75,
          points: [{ x, z, dwell: 0, lookAt: null | { objectId } | { x, y, z } }] }
```
- 坐标单位是米，存世界坐标 XZ。路线**不跟着物料移动**（图纸上画的线就是线）；被看的物料挪了，看向目标跟着走，因为存的是 objectId。
- 被看的物料删掉以后：这个点退回「看前方」，属性栏写「目标已删除」，路线照常能播。
- 放在 `layout` 里，所以撤销、多方案、复制方案、导出导入、自动保存都自动带上。要改的只有 `validateLayout` / `restore` / `layout()`：保留并校验 `routes`（数字有限、数组长度上限、id 唯一、approach 枚举、speed > 0、dwell ≥ 0）。校验失败就丢掉路线并提示，不影响物料。
- **不升版本号**，仍是 version 2，`routes` 可选，旧数据没有它照样能读。已知代价：用旧版下载编辑器打开新文件会丢路线，在使用说明里写一句。
- 编辑操作照现有方式进撤销：拖动松手、增删点、改属性各算一步；拖动过程中不算。
- 当前选中哪条路线、播放进度、平面图的缩放平移，都不存进方案。

## 4. 3D 播放
- **时间轴**（纯函数，能单测）：`compileRoute(route, getObject)` 把路线拆成一段段：「走」（长度 ÷ 走速）、「转身」（拐角处原地转，每 90° 约 0.4 秒）、「停留」（dwell 秒）。`sampleRoute(compiled, t)` 返回这一刻的位置、身体朝向、默认视线、是在走还是停、走到第几个点。拖进度条时每次都直接从时间表算，往回拖到同一时刻，结果一定一样。
- **播放条**：路线下拉框（大方案 / 子方案）、播放/暂停、进度条（按时间，停留点有刻度，点刻度跳过去）、当前时间 / 总时长、速度 ×0.5 / ×1 / ×2、「总览 ↔ 第一人称」切换、「视线归位」、「回到路线图」、「退出」。
- **总览**：用现有的轨道相机看全局，地面画路线、停留点编号，游客模型沿线走。
- **第一人称**：相机放在游客位置 + 眼高，隐藏游客自己的模型。点画面锁定鼠标，移动鼠标转头（上下有限位）；Esc 释放鼠标并暂停。走路时默认看前方，停留时默认看目标，鼠标转头是叠加在默认视线上的。暂停时也能转头。拖进度条或切换路线时，转头偏移清零。
- **游客模型**：临时建一个游客人物，不进方案数据。走的时候放 Walk 动画，停的时候放 Idle，动画进度跟时间轴走，暂停时动画也停。`people.update(dt)` 跳过这个人，避免动画被推两次。模型还没加载好时，先用一个胶囊占位。
- **键盘**：空格是播放/暂停；路线模式下 WASD 不起作用；输入框里打字（含中文输入法）不拦截快捷键。窗口失焦就暂停。
- **模式统一**：editor / freeWalk / routeEdit / routePlay 四种，同一时间只有一种模式控制相机和键盘。进入和退出都走同一对函数，退出时恢复进入前的相机、轨道中心、FOV 和选中状态。切换方案、导入、删除正在播的路线，都先退出播放。

## 5. 模块落点
| 文件 | 职责 |
|---|---|
| `src/routes-model.js`（新） | 默认值、校验、新建/复制 id、碰撞检查（线段对物料旋转矩形 / 圆 / L 形占地，墙） |
| `src/routes-timeline.js`（新） | `compileRoute`、`sampleRoute`；纯函数，不碰 DOM 和场景 |
| `src/routes-plan.js`（新） | 平面图编辑器：SVG 绘制、坐标换算（世界 XZ ↔ 屏幕）、画/拖/插/删、缩放平移、左栏列表、右栏属性 |
| `src/routes-player.js`（新） | 3D 播放：游客、地面线、播放条、两种视角、鼠标转头 |
| `src/app.js`（改） | 接 layout / restore / validate；模式切换入口；animate 调播放器；给新模块一组窄接口（读物料、记撤销、提交保存） |
| `src/editor.html`（改） | 「路线」按钮、平面图容器、播放条；样式沿用现有，图标用 Lucide |
| `src/people.js`（改） | 支持「外部驱动」的人物：跳过统一 update，按给定时间设置动画 |
| `src/build.py`（改） | 按顺序打包新文件 |

新模块不能直接写 localStorage，也不能自己维护撤销，一律调 app 给的接口。
