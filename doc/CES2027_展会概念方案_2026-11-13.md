# CES 2027｜展会概念方案

## 0. 两个项目的共同点

| 项目 | 用户做什么 | 得到什么 |
|---|---|---|
| 平行宇宙 | 拍一张自己的照片 → 交给 Agent | 替换游戏里的一个角色，体验"另一个人生" |
| 机器人拍照 | 机器人给用户拍照 | 自己出现在各种不同场景里的 AI 图片 |

**共同内核**：都是"拿一张你的照片 → AI 把你放进另一个世界"。
区别只在深浅：机器人是"**看见**另一个世界的你"（一张图），平行宇宙是"**活进**另一个世界"（一段体验）。
所以概念不用硬凑，顺着"一张照片 → 另一个你"讲就行。

## 1. 方案 A：Multi-You｜你的平行宇宙（推荐主概念）

- **一句话**：Meet the other yous. / 遇见平行宇宙里的你。
- **故事**：展台是一个"宇宙入口"。机器人是守门的摄影师，给你拍一张"入场照"；
  这张照片先在大屏上分裂成十几个平行世界里的你（机器人项目），
  再挑一个世界真正"活一次"（平行宇宙项目）。
- **展台动线**：入口机器人拍照 → 场景墙/大屏刷出多个"你" → 游戏体验位。
- **视觉**：镜面、门洞、网格分屏、"同一张脸在不同世界"的拼图主画面。
- **优点**：平行宇宙本来就是项目名，零翻译成本；机器人自然成了"入口"，两个项目有先后关系而不是并排摆。
- **风险**：如果以后展品换了，"宇宙"这个大词仍能装下新的 AI 生成类项目，可调整性好；
  但如果只剩机器人一个项目，略显名不副实。

## 2. 方案 B：One Photo, Infinite Lives｜一张照片，无限人生

- **一句话**：Snap once. Live infinite lives.
- **故事**：不讲世界观，直接讲流程——**拍 → 变 → 活** 三步，对应三个区域。
- **展台动线**：地面/顶部大字 1·2·3 引导，路人 3 秒看懂。
- **视觉**：干净的科技白 + 三个大数字，最容易用张力布 + 屏幕做出来，最便宜。
- **优点**：最好懂，最适合"没人讲解也看得懂"；老板最容易接受。
- **风险**：比较"功能说明书"，记忆点弱，拍照传播性一般。

## 3. 方案 C：AI 照相馆｜Future Photo Studio

- **一句话**：The world's first studio where the backdrop is infinite. / 背景无限的照相馆。
- **故事**：老式照相馆的反差感——机器人是摄影师，幕布换成 AI 生成的任何场景；
  平行宇宙是"走进照片里面去"。
- **视觉**：照相馆的布帘、补光灯、取片口（暖色复古 + 科技屏幕）。
- **优点**：亲切、有温度，旁边就是 Creator Space，创作者天然爱拍照分享；道具多为灯和布，成本可控。
- **风险**：偏"消费娱乐"，如果参展目的是谈 B 端合作，显得不够硬核。

## 4. 方案 D：宇宙护照｜Multiverse Passport（可做 A 的玩法外挂）

- **一句话**：Get your passport to the multiverse.
- **故事**：机器人拍的照片就是"护照照片"；每去一个场景/体验一次游戏就盖一个章；
  最后扫码领走带自己照片的电子/打印护照卡。
- **优点**：有收集感、有带走的东西，扫码领图顺便留下联系方式（留资）。
- **风险**：多一层流程，现场人多时会排队；需要打印或小程序/网页支持。

## 5. 方案 E：You, Rendered｜你被重新渲染

- **一句话**：Any face. Any world. Rendered in seconds.
- **故事**：强调技术能力——"AI Agent 能把任何真人实时放进任何内容"，
  两个项目都是这项能力的演示。
- **优点**：最适合面向投资人、游戏厂商、品牌方谈合作。
- **风险**：普通观众吸引力弱，必须配实时效果演示，否则只是口号。

## 6. 推荐组合

**主概念用 A（Multi-You），动线用 B 的"拍 → 变 → 活"三步当导视，D 的护照作为可选加分项。**

理由：
1. A 让两个项目变成"先后两步"，不是两个互不相干的摊位；
2. B 的三步大字解决"路人看不懂"，几乎不花钱；
3. 结构上只靠张力布画面 + 屏幕内容表达概念，展品变了只换画面和屏幕内容，不推倒结构（符合项目上下文 5.1）。

如果老板说"这次主要是去谈生意"，主概念换成 E，A 的体验做演示环节。

## 7. 选概念前要先问清的事

| 问题 | 为什么影响概念 |
|---|---|
| 这次参展主要为了什么：路人曝光 / 谈合作 / 媒体？ | 决定选 A/C（大众）还是 E（B 端） |
| 平行宇宙里的"游戏"是自家的还是别人的？角色有版权问题吗？ | 展示画面能不能直接用游戏截图 |
| 机器人出图、换角色各需要几秒？ | 超过 30 秒就要设计等待区，否则流程卡住 |
| 生成的图片怎么给用户：扫码、打印、发邮件？ | 决定要不要护照卡/打印机/留资环节 |
| 在美国给观众拍照，用什么方式取得同意？ | 入口需要同意提示牌/勾选，影响入口设计 |
