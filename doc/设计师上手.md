# CES 展台编辑器 · 设计师上手

给第一次拿到这个工具的设计师（和帮 TA 的 AI 助手）看。前半给人看，后半给 Agent 看。

## 这是什么

一个网页版 3D 展台草图。你把 Figma 里的设计图贴到展台物料的面上（前台、L 型台、吊楣、电视屏幕、易拉宝、墙……），在 3D 里看大概效果。**预览用，不是印刷稿。**

**不用安装、不用部署、不用连 MCP。** 一个 HTML 文件，用 Chrome 双击打开就能用。

## 你会收到

| 文件 | 是什么 |
|---|---|
| `CES展台编辑器.html`（名字可能不同） | 编辑器本身，离线可用 |
| `xxx.json`（可选） | 展台方案。不给的话编辑器里自带默认方案「02」 |

## 五步走完

1. **打开**：用 Chrome 双击 HTML。收到了 JSON 就点顶栏「导入」选它（会多一个方案标签，不覆盖别的）。
2. **进贴图**：点顶栏最右边的「物料」。左栏列出「可贴图的面」。想贴的面不在列表里 → 点「管理贴面」，在 3D 里点那个面加上，再点「保存并退出管理模式」。
3. **拿尺寸做稿**：左栏点一个面 → 面板头部尺寸右边的**复制图标** → 到 Figma 里 ⌘V，得到一个同比例的空画框（1 米 = 1000 像素，名字就是这一面，比如「前台 12 正面」）。在这个画框里做设计。
4. **贴回来**（三种方式任选）：
   - **复制粘贴（最省事）**：Figma 里选中画框 → ⇧⌘C（复制为 PNG）→ 回到编辑器打开这一面的面板 → ⌘V。
   - **贴链接（改稿后一键更新）**：Figma 里右键画框「复制链接」→ 粘到面板输入框 →「贴上」。之后改了稿点「取最新」。第一次要连 Figma，见下方「令牌」。
   - **拖文件**：从 Figma 导出 PNG，拖到 3D 里亮着的面上或面板虚线框里。
   - 贴上后可调：完整显示 / 铺满、大小、左右上下、转 90°。⌘Z 撤销。
5. **交回**：顶栏「导出」→「导出当前方案」，把下载的 JSON 发回。图片已经打包在里面，对方「导入」就能看到。

## 令牌（只有「贴链接」才需要）

- 获取：Figma 左上角头像 → Settings → Security → Personal access tokens → 生成，权限勾「File content: Read」，复制那串 `figd_…`。
- 贴进面板点「连接」。只存在你这台电脑的这个浏览器里，不会进导出文件。
- 次数限制：每次「贴上」「取最新」算一次。文件所在团队如果是免费套餐、或你是查看 / 协作席位，一个月只有几次；付费套餐的完整 / 开发席位基本够用。次数不够就用「复制粘贴」或「拖文件」，不受限。

## 常见问题

- **3D 里没有亮面**：还没选面，先「管理贴面」。
- **「这张图在本机找不到了」**：换了浏览器或电脑。让对方重新发带图片的导出 JSON，或重新贴。
- **改的东西会丢吗**：实时存在当前浏览器里，刷新还在。换电脑 / 清浏览器数据会丢，重要的随时「导出」。
- **别用旧版编辑器打开新文件**：贴图会丢且不报错。用对方最新发你的 HTML。

## 给 Agent 看

你的用户是设计师，在用一个单文件 HTML 编辑器给 3D 展台贴图。按下面的事实帮 TA，不要猜。

**环境事实**
- 无需安装、部署、构建、MCP。编辑器是一个自包含 HTML，Chrome 打开即用；需要联网的只有「贴 Figma 链接」。
- 不要修改编辑器 HTML 文件，也不要手改方案 JSON 里的 `assets`（图片数据，带校验，改坏了整份导入失败）。
- Figma 个人令牌只让用户自己贴进编辑器面板；不要写进任何文件、命令或聊天记录。

**能帮的事**
- 帮用户按「五步走完」排查卡在哪一步。
- 做稿：画框尺寸以编辑器面板复制出来的为准（1 米 = 1000 像素）。如果你接了 Figma 的 MCP，可以帮用户在 Figma 里批量建同名画框、找画框链接（右键「复制链接」的那种 `figma.com/design/<fileKey>/…?node-id=1-3`）。
- 检查交回的 JSON（只读）：
  - 方案在 `plans[]` 里，每个方案的内容在 `plans[i].layout`；物料在 `layout.objects[]`，贴图在物料的 `decals` 里，键是面名（`front` 正面 / `back` 背面 / `left` 左侧 / `right` 右侧 / `top` 台面 / `endA` `endB` L 台端头 / `screen` 屏幕）；墙在 `layout.room.decals`，键 `A` / `B`。
  - 每个贴图的 `assetId` 应能在顶层 `assets` 里找到；找不到 = 导出时图丢了，让用户重新导出。
  - `source.kind` 为 `figma` 的带原链接，`file` 的是粘贴 / 拖入的。

**做不了的事**（如实告诉用户，不要绕路）
- 不能替用户在编辑器里点按钮贴图；没有命令行批量贴图入口。
- 不能把 Figma 稿实时同步到编辑器；改稿后要用户点「取最新」或重新粘贴。
