# Figma 贴图 · 确认版需求

对照样品：`doc/mock/figma-decal/`（`python3 doc/mock/figma-decal/build.py` 生成，端口 8878 打开 `/doc/mock/figma-decal/`）。样品 v2 的左栏是「勾选框」，**正式版改成下面第 1 条的「选面」方式**，其余以样品为准。

## 1. 常规模式：先选出「可贴图的面」

- 选中一个能贴的物体后，左栏出现「可贴图的面」：列出已选的面（如「正面」「背面」），每个都能删除（× 图标）；下面一个「选面」按钮。
- 点「选面」→ 进入选面状态：鼠标移到**这个物体**的面上，该面高亮；单击切换选中（选中的面保持蓝色）；左栏变成「保存 / 取消」。点「保存」才生效，「取消」或 Esc 放弃。选面期间不能拖动、旋转物体。
- 墙面：左栏「场地」区同样有「可贴图的墙面」+「选面」，选面时只能点 A/B 墙内侧。
- 能贴的面：前台（正、背、左、右、台面）、A/B 墙内侧、易拉宝正面、亚克力立牌插纸正面。其他物件不出现这块。
- 删除一个已经贴了图的面：同时删掉这面的贴图（可撤销）。

## 2. 贴图模式

- 视图条「步行浏览」左边加「贴图」按钮，点击进入/退出；Esc 先关面板，再按一次退出。与步行浏览、路线编辑互斥。
- 进入后：取消当前选中；所有「可贴图的面」淡蓝色亮起（不透明度约 0.24）；点物体不会选中它。顶部提示「贴图模式 · 点亮着的面添加设计图 · Esc 退出」；一个可贴面都没有时提示去左栏选面。
- 点亮着的面 → 右侧贴图面板；点没亮的地方 → 关面板。
- 往画布拖图片：只有拖到亮着的面上才接受（高亮该面、松手贴上并打开面板）；其他地方鼠标显示「不能放」、松手无反应。常规模式下拖图片到画布无任何反应。
- ⌘V：贴图模式下，粘贴剪贴板图片到鼠标所在的亮面，否则贴到面板当前面。

## 3. 贴图面板

- 头部：物体名 + 这面实际尺寸（如「2.7 × 1 米」）+ × 关闭。同一物体有多个可贴面时，头部下方切换面（已有图的面带小圆点）。
- 还没贴：**Figma 链接为主**——「粘贴 Figma 画框链接」输入框 +「贴上」（回车同效）；下面一小行「或拖图片到这里 · ⌘V · 选文件」。
- 已贴上：缩略图；摆法「完整显示 | 铺满」；大小 30–200%；左右、上下 −50～+50；方向 ⟲90° ⟳90° 复位；挪到（同一物体的其他可贴面，目标已有图时注明会替换）。最后一行按来源：链接贴的「取最新 / 换链接 / 删除图标」，上传的「换图 / 删除图标」。
- **不要**：「正对这个面」按钮、比例不符提示文案、「铺满」后的括号说明。
- 错误：非图片文件、链接取不到、令牌无效等用一行红字，写人话（见样品）。
- 第一次用链接：面板提示去 Figma「设置 → 安全 → 个人令牌」生成令牌，输入后「连接」。

## 4. 数据与接口（AI 推荐，用户授权按此执行）

- **方案数据**（随方案保存/撤销/导出）：物体 `decalFaces:['front',…]`、`decals:{front:{source,assetId,fit,scale,ox,oy,rot}}`；墙放在 `room.decalFaces/decals`，键 `A`/`B`。`source` 为 `{kind:'figma',url,fileKey,nodeId}` 或 `{kind:'file'}`。`validateLayout` 必须认识并校验这些字段（目前会丢弃未知字段）。不升存储版本号（同游客路线做法）：旧版编辑器打开新文件会丢贴图。
- **图片**：按内容 hash 去重，存浏览器 IndexedDB（localStorage 约 5MB 放不下）；方案里只存 `assetId`。先存图成功，再存引用。长边上限约 2048 像素（预览用，不是印刷稿）。
- **导出 JSON**：顶层加 `assets:{assetId:{mime,width,height,base64}}`，只含导出范围内用到的图；导入时先校验再追加，失败不污染现有方案。「下载编辑器」不带用户图片、不带令牌。
- **Figma**：浏览器直连 `api.figma.com`（2026-11-14 实测 CORS 可用，无需本机中转）。从链接解析 fileKey 与 node-id（`1-3` → `1:3`），调 `GET /v1/images/:key?ids=…&format=png`，再下载返回的图片地址存成 asset。**取图那一步的跨域未经真令牌验证**：若图片地址不允许网页读取，停下汇报，不要自行加中转服务。令牌是编辑器本机设置：存 localStorage，不进方案 JSON、不进导出、不进日志。
- **渲染**：每个贴图是物体组下的一块平面（墙则在 roomGroup 下），随物体移动/旋转/隐藏/复制；`geometry()`、`buildRoom()` 重建后从数据恢复。按面实际尺寸画一张画布纹理（摆法、大小、偏移、旋转都在画布里算，不拉伸），sRGB、不受色调映射。面的位置/尺寸参照样品 `mock.js` 的 `faceSpec`。

## 5. 不做

实时同步 Figma、同一面叠多张图、曲面/圆桌/L 型台/电视屏、裁切框、印刷出血与色彩校样。
